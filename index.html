Ketentuan Lisensi DevWorksID
1. Kepemilikan Source Code

Setelah proyek selesai dan pembayaran lunas, seluruh source code menjadi milik klien sepenuhnya. Klien berhak memodifikasi, mengembangkan, atau memindahkan proyek ke developer lain.

2. Hak Penggunaan

Klien mendapat hak penuh untuk menggunakan hasil proyek untuk keperluan komersial maupun non-komersial tanpa batasan waktu.

3. Garansi & Dukungan

DevWorksID memberikan garansi bug fix selama 30 hari setelah proyek diserahkan. Dukungan teknis di luar masa garansi tersedia dengan biaya terpisah yang disepakati bersama.

4. Kerahasiaan

DevWorksID menjaga kerahasiaan data dan informasi bisnis klien. Kami tidak akan membagikan informasi proyek kepada pihak ketiga tanpa izin tertulis.

5. Portfolio

DevWorksID berhak menampilkan hasil proyek (screenshot/deskripsi umum) sebagai portfolio, kecuali klien meminta sebaliknya secara tertulis.

6. Pembatalan

Jika klien membatalkan proyek setelah pengerjaan dimulai, biaya yang sudah dibayarkan tidak dapat dikembalikan sesuai dengan progress yang telah dikerjakan.
